# mind_body_HRV_systematic_review

This repository contains the data from a systematic review and meta-analysis. It includes the data extracted from the eligible studies, which can be used to reproduce the primary analyses, the complete search strategy, the PICOS table, the risk of bias assessement with the reasons for each judgement and the extracted data on which the meta-analysis was performed.  

Overview

This repository contains the supporting materials for a systematic review with meta-analysis.

Contents

"data_extracted_metanalysis.xlsx": Data of the included studies that were extracted to perform the main analysis

"search_strategy_and_exclusions.xlsx": Search strategy and exclusions with reasons. 

"ROB2_crossover_v2.xlsm": Risk of bias assessment for the crossover trials.

"ROBINS-I_v2_repository": Risk of bias assessment for the non-randomized trials. 

"PICOS table": eligibility criteria.

"PRISMA_2020_checklist": the completed PRISMA checklist with references to the manuscript sections
