# mind_body_HRV_systematic_review
This repository contains the data from a systematic review and meta-analysis. It includes the data extracted from the eligible studies, which can be used to reproduce the primary analyses, as well as the complete search strategy.

Overview
This repository contains the supporting materials for a systematic review with meta-analysis.

Contents
"": Data of the included studies that were extracted to perform the main analysis
"search_strategy_and_exclusions.xlsx": Search strategy and exclusions with reasons.
